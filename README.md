# Shankhnaad Option 2

1. Extract the ZIP and upload its contents to the repository root. Keep assets/ intact.
2. Commit to main.
3. In Settings > Pages, choose Deploy from a branch, then main and /(root), and save.
4. Open the URL shown in Settings > Pages when deployment completes.

No build or install is required. The forms open a prefilled WhatsApp message.
The visitor must press Send in WhatsApp. Edit content.js to configure media.
